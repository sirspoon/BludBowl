How it would go into the game

  • Same place as now. The dice tumble where the block dice already appear, waiting for the Roll button, then settle where they'd be shown today.
  • The result is rolled when you press the button. The animation only shows it, so it can't change the odds, replays or two-device play.
  • Dice colours per team, set in the team's setup. They start as the team's two kit colours, can be changed freely, and a Use team colours button puts them back. If the two colours are too alike to read, the pips are darkened or lightened until they do.
  • Two settings under Settings: animate block dice, and animate other rolls. Both are off by default for anyone whose phone asks for reduced motion. The computer's rolls and fast test matches stay instant.
